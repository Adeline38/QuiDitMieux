# QuiDitMieux

QuiDitMieux est un site d'enchères entre particuliers accessible à tous. 
Sans compte, n'importe qui peut rechercher et consulter les objets en vente. 
En revanche, l'inscription et la connexion sont obligatoires pour proposer un article ou participer à une enchère.

# Fonctionnalités :

• Accès public : Consultation et recherche d'objets sans inscription.

• Espace membre : Création de compte et connexion sécurisée.

• Ventes : Dépôt d'annonces avec description et prix de départ.

• Enchères : Participation active aux ventes en cours pour les membres connectés.
